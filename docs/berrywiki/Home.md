# ZeroProb.jl

Probabilistic programming with an explicit TPU-style simulation adapter.

ZeroProb integrates probabilistic workloads without overstating hardware support; its TPU-style path is explicitly CPU simulation.

This BerryWiki notebook is the human-facing index; the repository's machine-readable state file is authoritative for automation.
